## 🔬 项目作品

### 1️⃣ 非接触式呼吸检测系统
**硕士课题 | 2024.09 - 2026.03**

[查看项目详情 →](projects/01_rppg_respiratory_detection/README.md)

基于 FactorizePhys 模型进行创新性改进，提出融合运动感知注意力和自监督重建学习的呼吸率检测模型。

**项目背景：**
传统呼吸率检测需要接触式传感器，本项目实现通过普通摄像头视频进行非接触式呼吸监测。

**核心创新：**
- 设计双注意力机制（全局空间注意力 + 局部时间注意力）
- 基于 NMF 矩阵分解的因子化注意力模块（FSAM）
- 多任务学习框架：同时预测呼吸率 + 重建运动信号
- 预期性能提升 10-15%

**技术实现：**
- 使用 PyTorch 实现 700+ 行模型代码
- 3D-CNN 提取时空特征
- 自监督重建学习增强泛化能力
- 在 RPI 数据集上进行实验验证

**成果：**
- 完成从方案设计到代码实现的全流程
- 实验结果验证了方法的有效性
- 为后续研究奠定了技术基础

### 2️⃣ 实时多人健康监测系统
**全栈项目 | 2024.10 - 2025.08**

[查看项目详情 →](projects/03_realtime_health_monitor/README.md)

基于 rPPG（远程光电容积脉搏波）技术的非接触式生命体征监测系统，通过摄像头实时检测多人的心率、呼吸率等健康指标。

**系统架构：**
```
摄像头 → 视频流 → 人脸检测 → rPPG算法 → 信号处理 → 心率/呼吸率
                    ↓
              Flask后端 → WebSocket → 前端实时展示
```

**核心功能：**
- **非接触式检测**：无需佩戴任何设备
- **多人同时监测**：支持最多 3 人同时在线
- **实时可视化**：Chart.js 动态绘制心率趋势图
- **Web 应用**：完整的 Flask + Vue.js 前后端架构

**技术难点与解决：**
- 运动伪影抑制：采用 PCA/ICA 算法分离有用信号
- 光照变化鲁棒性：自适应阈值调整
- 实时性能优化：多线程处理，稳定 30fps

**部署成果：**
- 已成功应用于多个实验场景
- 检测准确率 > 95%
- 端到端延迟 < 200ms

### 3️⃣ 多人生理信号数据采集系统
**物联网项目 | 2025.01 - 2025.12**

[查看项目详情 →](projects/02_physio_data_acquisition/README.md)

分布式多终端生理信号采集系统，用于多受试者实验研究，实现视频录制与血氧仪数据的网络同步采集。

**系统架构：**
```
主节点（时间同步服务器）
    ↓ UDP多播同步
从节点 1 ─┐
从节点 2 ─┼→ 数据采集 → 中心存储
从节点 3 ─┘
```

**核心挑战：**
1. **时间同步**：设计 UDP 时间同步协议，实现多设备毫秒级同步（精度 < 100μs）
2. **硬件适配**：支持多种 USB 血氧仪（HID 协议），60Hz 采样率
3. **视频录制**：FFmpeg 硬件编码优化，防丢帧机制

**项目成果：**
- 成功应用于 30 名实验人员的实验数据采集
- 系统同步精度 < 100μs，丢帧率 < 0.1%
- 支持最多 8 台设备同时工作
- 编写完整的运维文档和使用指南

**技术亮点���**
- 主从架构设计，故障自动恢复
- 实时监控终端状态，异常告警
